## H1: Train Humanoids Fast, Accurate, Low Man-Hours

### Tổng quan bài toán 
- Huấn luyện humanoid nhanh, chính xác, ít công sức
- Khảo sát và thử nghiệm phương pháp huấn luyện humanoid đơn giản, hiệu quả hơn; đồng thời thiết kế mô hình thu thập dữ liệu DENSO để huấn luyện robot.

### Sản phẩm đầu ra sau 3 tháng
- Quy trình thu thập dữ liệu chuẩn
- Báo cáo so sánh phương pháp huấn luyện
- Demo kỹ năng học được

### Công nghệ gợi ý
Isaac Sim, Imitation Learning / Reinforcement Learning (RL), Dữ liệu điều khiển từ xa (Teleoperation Data), PyTorch, Robomimic
